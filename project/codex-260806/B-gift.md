## 발견

1. **[P0] · `ReportGift.jsx:532-540` · 혼인·출산 1억 공제를 폴백이 전혀 반영하지 않음**

   재현: 거주 성년 자녀가 부모에게서 현금 2억원 증여, 혼인 전후 2년 요건 충족, `marriageDed=yes`, 엔진 실패.

   - 화면 출력: 과세표준 1억5천만원, 세액 1,940만원
   - 올바른 값: 기본 5천만원+혼인 1억원 공제 → 과세표준 5천만원, 산출 500만원, 신고공제 15만원 → **485만원**
   - 차이: **1,455만원 과대**

   `marriageDed`/`childbirthDed`는 엔진 요청에는 boolean으로만 전송되어 실제 혼인일·출생일 및 과거 혼인·출산 공제 사용액도 검증할 수 없다(`:301-310`). 날짜 입력 자체가 없으므로 미래일·2년 경계·혼인+출산 통산 1억원을 프런트에서 검증하지 못한다.
   수정안: 폴백에 `min(남은 혼인·출산 공제, 1억)`를 반영하고, 증여일·혼인일·출생/입양일·기 사용액을 입력/전송한다.

2. **[P0] · `ReportGift.jsx:533-540` · 10년 합산은 더하지만 §58 기납부세액공제를 전부 누락**

   재현: 성년 자녀가 동일 부모에게서 기존 1억원(당시 기본공제 5천만원 적용), 이번 1억원 증여, 엔진 실패.

   - 화면 출력: 과세표준 1억5천만원, 산출 2,000만원, 신고공제 60만원 → **1,940만원**
   - 올바른 값: 합산 산출세액 2,000만원 − 기존 증여분 산출세액 500만원(§58) − 신고공제 45만원 → **1,455만원**
   - 차이: **485만원 과대**

   `priorGiftDeductionUsed()`는 엔진 바디용으로만 쓰이고(`:293-321`), 폴백은 `priorGiftDed`와 기납부세액을 읽지 않는다.
   수정안: 폴백에서도 기존 증여분의 산출세액을 계산해 §58 공제 후 §69 신고공제를 계산한다.

3. **[P0] · `ReportGift.jsx:537-540` · 세대생략 할증을 0원으로 고정**

   - 올바른 값: B의 12억원 사용 → **2억9,100만원**

   요청 식별자·주소 일치 확인·취소 처리가 없다.

13. **[P1] · `ReportBurdenedOptimize.jsx:193-206` · 부분 엔진 응답을 정밀 결과로 승인하고 누락 세액을 0원 처리**

   재현: 엔진이 다음처럼 응답한다고 가정한다.

   ```json
   {
     "calc": {
       "채무없는경우세액": 100000000,
       "시뮬레이션결과": [{"채무비율": 0, "총세부담": 100000000}]
     }
   }
   ```

   현재 조건은 충족하므로 `precise=true`가 되고, 없는 `절세액`을 `0`으로 처리해 **“최대 0원”**을 정밀 결과로 표시한다. 올바른 출력은 **정밀 계산 필요**이며, 절세액을 0원으로 단정하면 안 된다.
   수정안: `최적총세부담`, `최적채무비율`, `절세액`, 각 시뮬레이션의 증여세·양도세·취득세·총세부담을 숫자형 필수값으로 검증한다.

## 발견 없음 / 범위 확인

- `GIFT_BRACKETS`와 `calcGiftBaseTax`, `INH_BRACKETS`와 `calcInhBaseTax`의 다섯 구간·누진공제는 현행 §26·§56과 일치한다.
- `giftDeduction()`의 관계 방향은 “수증자가 누구에게서 받는가” 기준으로 올바르다. 배우자 6억원, 직계존속 5천만원/미성년 2천만원, 직계비속 5천만원, 기타친족 1천만원이다.
- `ReportGift.jsx`의 부담부증여는 로컬 세액 폴백을 하지 않고 엔진 실패 시 세액 표시를 차단한다. 이 세 파일 안에는 채무인수분 안분·양도차익 산식이 없으므로 그 엔진 산식 자체는 검증할 수 없었다.
- `ReportBurdenedOptimize.jsx`도 로컬 세액 폴백은 없다.

현행 조문 기준은 [상증법 §53·§53의2·§55~§58](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1017648003), [§57](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1017648003), [§69](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029616341), [§19~§21](https://law.go.kr/LSW/lsInfoP.do?lsiSeq=252781), [§24](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029615611)를 대조했다.
