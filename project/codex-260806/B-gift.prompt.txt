파일은 반드시 UTF-8로 디코딩해 읽어라 — PowerShell Get-Content/Select-String은 -Encoding utf8 필수, rg/cat이면 그대로.

서론·계획·다짐 금지. 지금 즉시 도구로 지정 파일을 실제로 열어 확인한 뒤 발견만 보고하라.

당신은 한국 세무·웹 도메인의 적대적 코드 리뷰어다. 대상: **상속·증여 계열 계산기 3종**
- `project/src/ReportGift.jsx` (876줄) — 증여세 (부담부증여 포함)
- `project/src/ReportInheritance.jsx` (605줄) — 상속세
- `project/src/ReportBurdenedOptimize.jsx` (368줄) — 부담부증여 최적화

## 배경
정적 사이트(React 18 UMD + @babel/standalone). 원격 엔진 `/v1/calc/gift`·`/v1/calc/burdened-gift` 등을 호출하고
**응답이 없으면 프론트 «간이 폴백»으로 계산**한다 → 폴백 산식·세율표도 사용자에게 노출되므로 동일하게 검증하라.

## 이미 수정한 것 — 다시 보고하지 마라
금액 입력 파서(`replace(/[^0-9]/g,'')` → `window.jtSetNumericAns` 공용 헬퍼로 교체). 날짜·업종코드는 의도적으로 그대로.

## 무엇을 볼 것 (직접 손계산해 대조하라)
### A. 증여세
- `GIFT_BRACKETS`/`calcGiftBaseTax` 가 상증법 §56 현행 세율표(1억 10% / 5억 20%·누진1천만 / 10억 30%·누진6천만 / 30억 40%·누진1.6억 / 초과 50%·누진4.6억)와 맞는가.
- `giftDeduction` 증여재산공제(§53): 배우자 6억 / 직계존속 5천만(미성년 2천만) / 직계비속 5천만 / 기타친족 1천만 / 비친족 0.
  **누가 주고 누가 받는지 방향이 뒤바뀌지 않았는지** 특히 확인하라.
- 혼인·출산 증여공제(§53의2): 최대 1억, **혼인+출산 합산 1억 한도(§53의2③)**, 요건(혼인 전후 2년·출생 2년 내).
- 10년 내 사전증여 합산(§47②)과 기납부세액공제(§58), 세대생략 할증(§57 30%·미성년 20억 초과 40%).
- 신고세액공제(§69 3%).
- **부담부증여**: 채무 인수분은 증여자에게 양도소득세, 나머지는 수증자에게 증여세. 안분 비율·양도차익 계산이 맞는가.

### B. 상속세
- `calcInhBaseTax` 세율표(§26 — 증여와 동일 구조)가 맞는가.
- 상속공제: 기초공제 2억(§18), 배우자상속공제(§19 — 최소 5억·법정상속분 한도·30억 한도), 일괄공제 5억(§21),
  금융재산공제(§22 최대 2억), 동거주택상속공제(§23의2). **일괄공제와 기초+인적공제 중 «큰 쪽» 선택**이 구현됐는가.
- 공제 종합한도(§24), 사전증여 합산(§13 상속인 10년·기타 5년).

### C. 코드 결함
- 엔진 응답 실패·부분 응답 시 폴백 전환 조건, 엔진 값과 폴백 값이 섞이는 경로.
- 비동기 경쟁(조건 변경 후 이전 응답이 덮어쓰기), `showIf` 로 숨겨진 stale 값이 계산에 유입.
- 날짜 입력 검증(미래·역순), 경계값(공제액과 정확히 같은 금액, 과세표준 0/음수).
