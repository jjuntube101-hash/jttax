파일은 반드시 UTF-8로 디코딩해 읽어라 — PowerShell Get-Content/Select-String은 -Encoding utf8 필수, rg/cat이면 그대로.

서론·계획·다짐 금지. 지금 즉시 `git diff HEAD~3..HEAD` 와 지정 파일을 실제로 열어 확인한 뒤 발견만 보고하라.

당신은 한국 세무·웹 도메인의 적대적 코드 리뷰어다. **R2 — 당신의 A~E 배치 지적 반영본 검증**이다.

## 반영한 것 (이게 옳은지, 새 결함을 만들지 않았는지 검증하라)

### 1. [A P0] 양도세 단기보유 세율 — 자산별 분기 (소득세법 §104①2호·3호 원문 확인)
`ReportCGT.jsx` 에 `isDwellingClass`·`shortRate` 신설.
· 주택·조합원입주권·분양권 1년미만 70%/1~2년 60% · 그 밖 50%/40%.
· 비사업용 토지 2년 미만은 §104④ 후단(기본세율+10%p 와 단기세율 중 큰 세액) 반영.
· `tests_cgt_shortterm.js` 신설 — 세율표뿐 아니라 «실제 계산 배선»까지 단언.

### 2. [A P0] 「취득 당시」 조정대상지역을 «현재 지역»으로 대신 쓰던 것
`acqAdjustedZone` 문항 신설(예/아니오/모름 — 모름은 보수적으로 요건 있음).
엔진 payload `regulated_at_acquisition` 1곳 + 폴백 비과세 판정 2곳에 배선.

### 3. [B P1] 상속세 「6명 이상」을 6으로 전송하던 것
「7명 이상」 선택지 + 실제 인원 문항 추가. `inhChildCount()` 로 payload·폴백 공용.

### 4. [D P1] 국민연금 상·하한 고시 기간 만료
★ **확인된 새 값이 없어 숫자를 지어내지 않았다.** `pensionBoundsUntil: '2026-06-30'` 을 두고,
기간이 지났고 «실제로 상·하한 구간에 걸린» 경우에만 화면이 그 사실을 고지한다.
→ 이 «숫자를 지어내지 않고 사실만 고지하는» 처리가 타당한지 판단하라.

### 5. [E P0] 동의 없는 개인정보 전송 (ReportConvert.jsx)
「카톡으로 결과 전송」이 클릭만으로 입력·세액·분석을 Web3Forms 로 POST 하던 것 →
전송 전 무엇이 어디로 가는지 알리고 동의를 받는다(거부 시 복사·카톡 열기만).
사후 안내도 «실제로 한 일»만 말하게 수정. 리드 폼 동의문에 실제 전송 항목·처리위탁 명시.

### 6. [E P1] 공용 금액 파서 — 구분자 위치 미검증 + 구현 이중화
`1,2`→12·`1원2`→12·`12\n34`→1234 로 여전히 자릿수가 바뀌던 것 → 전체 형태 검증 후 제거.
그리고 `ReportReform2026.jsx` 가 나중에 로드되며 `window.jtMoneyDigits` 를 «다시 대입»해
Report.jsx 개선이 화면에 반영되지 않던 것(브라우저 실측으로 발견) → 대입 제거·참조만.
두 테스트 하네스도 Report.jsx 의 «그 구현»을 싣도록 교체.

## 아직 반영하지 «않은» 것 — 판단을 검증하라
당신이 A~E 에서 지적한 **폴백 누락**(증여 혼인공제·기납부세액공제·세대생략할증·비거주자 /
상속 사전증여·금융재산·동거주택·배우자 실제상속 / 취득세 법인·생애최초·농특세·일시적2주택 /
재산세 토지누진·세부담상한 / 종부세 재산세공제·특례·세부담상한 / 양도세 입주권 장특·1주택+입주권 중과)
은 **아직 손대지 않았다.**

내 판단: 이것들을 프론트에 다시 구현하면 «엔진을 한 벌 더 만드는 것»이라 새 오류를 낳는다.
대신 **폴백이 감당 못 하는 입력이면 숫자를 내지 말고 「정밀 계산 필요」로 차단**하는 것이
맞다고 본다(부담부증여 경로가 이미 그렇게 되어 있다 — `ReportGift.jsx` 의 `engineErr` 분기).
참고로 엔진은 현재 정상이다(`https://jt-tax-engine.fly.dev/health` → 200, 0.25s).
`index.html:117` 이 `window.JT_ENGINE_BASE` 를 라이브 엔진으로 지정하므로 폴백은 장애 시 경로다.

→ **이 방향이 맞는가?** 맞다면 계산기별로 «차단해야 할 조건»을 구체적으로 나열하라
  (어떤 답이면 폴백 숫자를 내면 안 되는가). 틀리다면 근거와 함께 반박하라.
