파일은 반드시 UTF-8로 디코딩해 읽어라 — PowerShell Get-Content/Select-String은 -Encoding utf8 필수, rg/cat이면 그대로.

서론·계획·다짐 금지. 지금 즉시 `git diff HEAD~2..HEAD` 와 지정 파일을 실제로 열어 확인한 뒤 발견만 보고하라.

당신은 한국 세무·웹 도메인의 적대적 코드 리뷰어다. **R3 — R2 지적 반영본 검증.**

## 채택해 반영한 것
1. **[P0] 국민연금 상·하한** — 당신 말이 맞았다. 웹으로 확인해 41만/659만·만료 2027-06-30 으로 갱신.
   상한 초과자 302,575 → 313,025원(브라우저 실측). 만료 고지 로직은 남겨 다음 7월 갱신을 알리게 했다.
2. **[P0] 「살 때 조정지역」 문항의 showIf** — 현재 지정과 무관하게 주택이면 항상 묻도록 변경.
   엔진 payload·폴백 2곳도 `adjustedZone` 종속을 끊고 `acqAdjustedZone` 단독으로 판정.
3. **[P1] 상속세 `numChildrenExact` 에 `tier:'quick'`** 추가.
4. **[P1] 전송 성공 전 「전달했습니다」** — `fetch` 응답(res.ok)으로 성공/실패 문구를 가른다.

## 기각한 것 — 반박하려면 근거를 대라
**[P0] 「폴백 기본세율표가 2025년 값(6/15/24/…/45%)이다」 → 기각.**
소득세법 **§55① 원문**을 법령 MCP 로 직접 조회한 결과 기본세율표는
`1,400만 이하 6% / 5,000만 이하 15% / 8,800만 이하 24% / 1억5천만 이하 35% /
 3억 이하 38% / 5억 이하 40% / 10억 이하 42% / 10억 초과 45%` 로 **코드가 옳다**.
당신이 제시한 16/25/34/45/48/50/52/55% 는 **§104①8호의 «비사업용 토지» 중과표**
(= 기본세율 + 10%p)다. §104①1호는 「제55조제1항에 따른 세율」을 그대로 참조한다.
그대로 고쳤다면 모든 양도세 폴백을 10%p 과대 계산할 뻔했다.
→ 이 판단이 틀렸다고 보면 **§55① 원문을 인용해** 반박하라. 맞다면 「기각 타당」이라고 확인하라.

  특히 2번은 문항 순서·`showIf` 연쇄·엔진 payload·폴백 2곳이 서로 어긋나지 않는가
  (`acqAdjustedZone` 미응답 시 기본 동작이 «보수적»인가).

- R1~R2 반영분에 회귀가 생기지 않았는가.
