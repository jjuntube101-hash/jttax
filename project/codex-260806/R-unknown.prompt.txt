  → `giftFallbackGaps` 에서 engineErr 를 «차단 사유»로 승격(why 문구 포함). 렌더의 engineErr 전용
    분기는 도달 불가가 되어 정리. 브라우저 실측으로 AI 0회·카카오 0·금액 0 확인.
- [P1] `isRegulatedArea: 'unsure'` payload 소실 → **엔진을 실제로 호출해 계약을 확정**했습니다:
    is_regulated_area 생략 → 3.5% 30,400,000 / 명시 → 12% 99,200,000 (3.26배)
    exclusive_area 생략 → 농특세 0 / 100㎡ → 1,600,000
    housing_count 1 로 축소 → 20,504,000 / 실제 2주택 조정 → 67,200,000
    regulated_at_acquisition=false → 24,845,000 / true → 209,970,000 (8.45배)
  → 그래서 «불확정 입력» 층을 신설해 `calc.precise` 여도 차단하도록 했습니다
    (acqFallbackGaps·cgtFallbackGaps 가 2층 구조: ①불확정 ②폴백 한계).
