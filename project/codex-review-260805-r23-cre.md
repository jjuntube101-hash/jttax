## 2. 변경 내역

수정 없음(read-only).

- [P1] · `project/src/ReportReform2026.jsx:433-463` · 재산세 중복분 공제 없이 `gross`에 세액공제를 바로 적용합니다. 현행법 종부세법 §9③의 재산세 공제는 개편안에서 손대지 않은 항목인데 누락됐습니다.

  재현: 1세대1주택, 공시가격 18억, 거주, 66세, 보유 12년, 거주 12년, 2026년.

  - 올바른 현행법 순서: 재산세 중복분 225,000원 차감 후 잔액 1,695,000원에 70% 공제(1,186,500원) → 종부세 508,500원, 농특세 101,700원, 합계 **610,200원**
  - 과다표시: **81,000원**

  수정안: 주택별 공시가격을 받거나 재산세 중복분 산식을 구현하고, `gross → 재산세공제 → 1주택 세액공제 → 농특세` 순서로 계산하십시오. 현재 테스트도 잘못된 공제액 1,344,000원을 정답으로 고정합니다(`project/tests_rf_reform2026.js:129`).

  - 코드 입력값: 거주용가액 20억 → 2027 공제 9억, 과표 7억7천만, 종부세+농특세 **6,972,000원**
  - 올바른 입력값: 실제 거주 주택 10억만 반영 → 공제 6억5천만, 과표 9억4천500만, 종부세+농특세 **9,702,000원**
  - 과소표시: **2,730,000원**

  수정안: `residentValue`의 주소 조회는 단일 선택·덮어쓰기 방식으로 바꾸거나, 복수 선택이면 “거주용은 1채만” 검증을 강제하십시오.

- [P3] · `project/src/ReportReform2026.jsx:405-406, 467` · 공개된 `window.jtRfCalcCRE`는 `residentValue` 하한을 0으로 고정하지 않습니다. UI는 음수를 막지만, 함수 직접 호출·외부 재사용 시 음수 공제비율을 허용합니다.

  재현: `{totalValue:2500000000, houses:'two', residentValue:-1000000000, adjusted:'no'}`, 2027년.

  - 코드 출력: 공제 2억, 총부담 **21,060,000원**
  - 0으로 클램프한 값: 공제 4억, 총부담 **18,540,000원**
  - 수정안: `Math.min(1, Math.max(0, resValue / totalValue))`로 하한도 제한하십시오.

## 3. 재발 방지

- 재산세 중복분 공제 후 세액공제 순서를 검증하는 회귀 테스트를 추가해야 합니다. 위 18억 사례의 정답은 총 610,200원, 세액공제 1,186,500원입니다.
- `residentValue` 자동조회는 1건만 유지하는 UI 테스트와 음수 직접입력 단위 테스트가 필요합니다.

## 4. 검증 결과

- UTF-8로 세 파일 전체를 읽었습니다: `Get-Content -Encoding utf8`.
- 현행법 MCP 확인: 종합부동산세법 §8(12억/9억), §9③(재산세 공제), §9⑤~⑨(공제는 재산세 차감 후 세액 기준), §10(세부담 상한), 농어촌특별세법 §5①8호(납부 종부세의 20%).
- 현행 계산 엔진 대조: 위 18억 사례는 **610,200원**, 재산세 공제 **225,000원**으로 반환됐습니다.
- 종부세 테스트는 CASE 8~12, **5개 시나리오·11개 assertion**뿐입니다. 재산세 공제·세부담 상한·음수값·거주용 자동조회 복수추가·정확히 공제경계·2028 중과/80% 비율은 커버하지 않습니다.
- `node project/tests_rf_reform2026.js` 실행은 불가했습니다. 환경에 `node` 실행 파일이 없습니다.
- 발견 없음: SSOT의 60→70→80% 공정시장가액비율은 `rfCalcCRE`의 연도별 호출에 실제 반영되며, 2026 현행 세율표는 MCP 현행법 §9①과 일치합니다. 다주택 공제 분모 0 및 상한 100% 클램프도 구현돼 있습니다. 정부안·재산세공제·세부담상한 미반영 고지는 `:1376-1382`에 명시돼 있습니다.

## 5. 미확인 사항

정부 발표 원문 PDF는 작업공간에 없고 공식 검색에서도 해당 발표자료 원문을 확보하지 못했습니다. 따라서 2027~2028 정부안의 세율·공제 수치 자체는 저장소 내 개조식/해설과의 일치만 확인했으며, 발표 PDF 대조는 검증 불가입니다.
