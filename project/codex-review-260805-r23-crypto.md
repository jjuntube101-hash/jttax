## 1. 작업 요약

가상자산 계산기 전체와 순수 계산 테스트를 읽고, 법령 MCP 원문(소득세법 §37·§64의3·§84 및 시행령 §88)과 대조했다. 중대한 법령 엔진 누락 2건을 발견했다.

## 3. 재발 방지

법령 SSOT를 법률 값뿐 아니라 시행령 §88의 총평균법·추계 50%까지 포함시키고, 법령 시행 상태를 고정 주석이 아닌 검증 가능한 메타데이터로 관리해야 한다.

## 4. 검증 결과

- `Get-Content ... -Encoding utf8`로 두 대상 파일 전체를 읽었다.
- jt-law-mcp 원문 확인 결과: 소득세법 §37⑤의 코인별 큰 금액 규칙, §37⑥의 동일 종류 전체 추계 근거, §64의3②의 250만원 공제·20%, §84 3호의 250만원 이하 과세 제외를 확인했다.
- 시행령 §88①은 총평균법, §88④·⑤는 증빙곤란 사유와 50% 필요경비율을 명시한다.
- `node .\tests_cr_crypto2027.js` 실행은 실패했다. 출력: `node ... 인식되지 않습니다`; 현재 read-only 환경에 Node 실행 파일이 없다. 따라서 테스트의 실제 PASS 결과는 검증하지 못했고, 파일 내용상 커버리지만 판독했다.
