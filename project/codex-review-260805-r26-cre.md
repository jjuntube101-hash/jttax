## 4. 검증 결과

- UTF-8로 소스를 직접 읽고, 2026년 재현값을 산식으로 검산했습니다: `gross 1,500,001 / rural 300,000 / stepsSum 1,800,001 / returnedTotal 1,800,000`.
- 세율 경계 반복문은 `base <= prev`와 구간별 `Math.min` 구조라 정확히 3억·6억·12억 등에서 한 구간 밀리는 신규 결함은 확인되지 않았습니다.
- 다주택 비율의 상한 클램프는 `Math.min(1, …)`로 작동합니다.
- 기존 Node 테스트는 이 환경에 `node` 실행 파일이 없어 실행하지 못했습니다.
