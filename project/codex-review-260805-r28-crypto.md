기존 소수점 붙여넣기 결함은 네 필드 모두에 동일하게 존재한다. 신규로 `#/report`가 이전 계산기 화면으로 잘못 복원되는 라우팅 결함 1건을 확인했다.

  - 재현: `localStorage.jt_report_sub = 'crypto'` 상태에서 `#/report` 진입.

  - 수정안: 파싱 결과가 `route === 'report'`이면 `jtNormSub(r.sub || 'hub')`를 즉시 반환하고, localStorage 복원은 라우터 해시가 없을 때만 수행한다.

## 3. 재발 방지

라우팅 테스트에 `#/report` + `jt_report_sub=crypto` 케이스를 추가하고, 금액 입력 테스트에 네 필드별 `*.00` 붙여넣기 케이스를 추가해야 한다.

## 4. 검증 결과

- 중간 행 삭제 상태 추적: `A:yes, B:no, C:yes`에서 B 삭제 후 `A:yes, C:yes`. `heldBefore`는 올바른 행 객체에 남는다. 이 경우 신규 결함 없음.
- 잘못된 서브라우트/해시:
  - `#/report/not-a-subroute` → 허브
  - `#/report/crypto?x=1` → 허브
  - `#/report/crypto/extra` → `crypto` 화면(세 번째 경로 조각 무시)
  - 위 경로에서 크래시·빈 화면 경로는 확인되지 않았다.
- `npm test` 실행은 환경에 `npm`이 없어 실패했다: `npm: ... 인식되지 않습니다`.
