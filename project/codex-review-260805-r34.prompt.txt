**R34 — R33 지적 2건 반영본 검증**이다. 이번 편집만 본다.

## R33 지적을 이렇게 반영했다

1. **[P2] 일부 연도만 문턱 미달일 때 「공제 축소가 증가의 원인」이 붙던 것** → 조건을 «근본»에서 고쳤다.
   당신은 `!result.some(r => r.notTaxable)` 을 제안했지만, 그러면 **문턱과 무관하게 세금이 줄어든
   경우에도** 「증가의 원인」이 붙는 원래 결함이 남는다(조건이 「1주택·비거주」뿐이었다).
   → `diff > 0`(실제로 늘어난 경우)에만 증가 설명, `diff < 0` 에만 감소 설명을 붙이고,
     `notTaxable` 연도가 섞이면 문턱 미달을 별도 문장으로 «먼저» 설명한다.
   **실측(브라우저)**: 당신 재현값(1주택·비거주 13억·50세·보유3년·거주0년) →
   「2028년 이후 종부세는 현행 대비 36만원 줄어듭니다(36만원 → 0원). 공시가격 합계가 과세
   문턱(14억원)을 넘지 않는 해에는 종부세가 아예 없습니다.」 — 모순 문구 사라짐. 2026년 36만원도 당신 계산과 일치.

2. **[P3] 조기 반환의 `heavy`/`fairRatio` 불일치** → 전면 채택.
   `heavy` 계산을 문턱 판정 «앞»으로 옮겨 정상 경로와 같은 값을 쓰게 했다.
   회귀 3항 추가: 2주택 비조정 2028 → `heavy=false·0.7` / 3주택 → `heavy=true·0.8`.

## 무엇을 볼 것 (이 편집만)
- 1번의 조건 재설계가 «모든 조합»에서 맞는가. `diff === 0` 인데 문턱 미달 연도가 섞인 경우,
  전 연도 0원인 경우, 다주택인 경우 등에서 문구가 사실과 어긋나는 조합이 남아 있는가.
- 2번이 정상 경로와 완전히 같은 값을 내는가.
- 이 편집이 R23~R33 반영분에 회귀를 만들지 않았는가.
