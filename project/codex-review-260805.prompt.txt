## 배경
- 정적 사이트(React 18 UMD + @babel/standalone 브라우저 트랜스파일, 빌드 툴체인 없음). 각 `Report*.jsx` 는 전역 스코프 스크립트로 순차 로드된다.
- 세제개편안은 **국회 미통과 정부안**, 가상자산 과세는 **2027.1.1 시행 예정**(소득세법 부칙 §5). 둘 다 확정법 엔진을 쓰지 않고 프론트에서 자체 계산한다.
- 법령 값은 각 파일의 SSOT 블록(`window.JT_REFORM_2026`, `window.JT_CRYPTO_2027`)에 집약.
- 주소 자동조회는 원격 엔진 `jt-tax-engine.fly.dev`의 `/v1/lookup/price` 를 `window.jtLookupHousePrice`(ReportProperty.jsx 정의) 경유로 호출한다.

2. **1세대1주택 판정을 «보유 2년»으로만 단순화한 것의 왜곡 범위**
   조정대상지역 취득분의 «거주 2년» 요건을 보지 않는다. 어떤 입력 조합에서 결과가
   실제와 갈리며, 그 오차가 이용자를 오도할 수준인가.

## 그 밖의 중점
### A. 세액 계산 정확성
**가상자산**: 필요경비(§37①3호) → 의제취득가액(2026.12.31 시가와 실제 취득가액 중 큰 금액, §37⑤) → 손실 통산 → 과세최저한(해당 과세기간 250만원 이하, §84 3호) → (소득금액−250만원)×20%(§64의3②) → 지방소득세 10%.
**종부세**: 기본공제 → 공정시장가액비율 → 구간 누진 → 세액공제(연령+보유/거주, 80% 및 금액한도) → 농특세 20%. 다주택 공제 산식 `4억 + 5억 × (거주용가액/합계액)`.

### B. 경계·수치
과세표준 0/음수, 세율 구간 경계값(3억·12억·10억·250만), 극단값(1조), 부동소수점 절사 순서, `Number('')===0` 누출, NaN 전파.

### C. 코드 결함
- `RfWizard` 위저드: showIf 로 문항이 나타나거나 사라질 때 인덱스가 어긋나 **문항을 건너뛰거나 갇히는** 경우가 있는가. 마지막 문항에서 앞 답을 바꿔 총 문항 수가 줄면?
- `RfAddrLookup`: 연속 조회 시 경쟁 상태(이전 응답이 나중에 도착), 엔진 응답 필드 신뢰, `status:'needs_unit'` 처리 후 값이 남는지.
- 전역 스코프 이름 충돌(신규 2파일끼리·기존 Report*.jsx 와), React key, 라우트 화이트리스트.
- `mdToHtml` 표 정규식이 기존 문서를 깨뜨릴 여지(파이프가 포함된 코드블록·인라인 텍스트 등).
- `Home.jsx` SVG viewBox `134.5 198.1 162.3 108.2` 가 두 path 의 실제 bbox 와 맞는가.

### D. 컴플라이언스
「정부안/시행예정이며 확정 아님」 고지의 충분성. 미반영 항목(§37⑥ 시행령 미제정, 재산세 중복분 공제, 세부담 상한) 고지가 오인을 막기에 충분한가. 세무사법 §12조의7 상 단정·과장·연고 표방 표현.

### E. 검산 스위트의 맹점
45건 통과가 커버리지 착시인지. **놓친 케이스를 구체적으로** 지목하라.
